Posicionamiento con CSS — Planetas

Tu misión es colocar los planetas correctamente sobre el fondo del espacio. Cada planeta debe aparecer en una posición distinta (esquinas, bordes o centro).

Instrucciones:

  • Descomenta cada bloque <div> con clase planet cuando lo necesites.
  • Solo puedes usar estas propiedades en tu CSS: border-radius, position, margin, top, bottom, left, right.
  • No uses display ni transform.
  • Para centrar horizontal o verticalmente, usa margin: 0 auto; y pon a 0 las coordenadas del eje que se centra.
